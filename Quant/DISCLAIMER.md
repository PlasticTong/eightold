# 风险声明

本目录中的文字、代码、参数和结果仅用于软件工程与量化研究教学，不构成投资建议、收益承诺或交易邀请。

## 必须知道的边界

- 历史收益不能保证未来收益；
- 示例行情是人工构造的数据，结果没有现实投资意义；
- 回测无法完整模拟盘口排队、市场冲击、部分成交、断线和极端行情；
- 真实交易还涉及账户权限、券商接口、交易所规则、税费和所在地区法律；
- 自动生成或自动下达交易指令可能属于程序化交易，应在实盘前向开户券商确认报告、测试和接入要求。

本模块不会读取 API Key，也没有真实下单功能。请勿把教学代码绕过测试后直接连接真实资金。

## 最低实盘门槛

即使未来增加模拟交易，也至少应完成：

1. 独立样本外与 walk-forward 验证；
2. 手续费、滑点、涨跌停、停牌和成交量限制建模；
3. 断线重连、重复下单、部分成交和仓位对账测试；
4. 最大仓位、单日亏损线和一键停止；
5. 长时间模拟盘运行；
6. 向券商确认程序化交易报告和接口权限。

中国证券市场程序化交易规则可从[中国证监会官方规定](https://www.csrc.gov.cn/csrc/c100028/c7480577/content.shtml)开始核对。
