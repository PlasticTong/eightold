# 风险控制：先考虑怎么不亏光

策略决定什么时候想交易，风险系统决定能不能交易、交易多少，以及什么时候必须停止。

## 仓位

全仓是教学上的简化，不是推荐做法。实际系统常按单笔可承受亏损计算数量：

```text
交易数量 = 账户权益 × 单笔风险比例 / (入场价 - 止损价)
```

还应限制单资产、单行业、相关资产和账户总风险敞口。

## 最大回撤

最大回撤衡量权益从历史峰值下降的最深幅度：

```text
drawdown = 当前权益 / 历史最高权益 - 1
```

它描述历史最差路径，但不能预测未来最坏情况。尾部风险可能远大于历史样本。

## 实盘系统风控

真实系统至少需要：

- 单笔和单日最大亏损；
- 最大持仓和最大下单数量；
- 价格偏离保护；
- API 限流和重试上限；
- 客户端订单 ID，防止重试造成重复下单；
- 部分成交与撤单处理；
- 本地仓位与券商仓位定期对账；
- 行情过期、断线或时钟异常时停止交易；
- 独立于策略进程的一键停止。

## 回测不应遗漏

- 手续费、税费和最低佣金；
- 买卖价差和滑点；
- 涨跌停、停牌与成交量；
- A 股 T+1 和整数手；
- 退市股票和历史指数成分；
- 训练集、验证集、测试集以及 walk-forward。
