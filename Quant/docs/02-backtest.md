# 回测系统：信号如何变成成交

一个可信的回测，重点不是曲线漂亮，而是时间顺序和成交假设足够明确。

## 本模块的事件顺序

```text
第 T 天收盘
   │
   ├─ 更新快慢均线
   ├─ 产生买入/卖出信号
   ▼
第 T+1 天开盘
   │
   ├─ 加入滑点
   ├─ 扣除手续费
   ├─ 更新现金与持仓
   ▼
第 T+1 天收盘
   └─ 按收盘价计算账户权益
```

如果使用第 `T` 天收盘价产生信号，又假设以同一个收盘价成交，就使用了当时尚未完整知道的信息。

## 成本模型

教学版本使用两个成本：

- 手续费：`成交金额 × commission`；
- 滑点：买入价上浮、卖出价下调。

```text
买入成交价 = 次日开盘价 × (1 + slippage)
卖出成交价 = 次日开盘价 × (1 - slippage)
```

真实市场还可能存在印花税、最低佣金、点差、市场冲击、借券费、涨跌停、停牌以及无法成交。

## 绩效指标

本示例输出：

- 总收益率：最终权益相对初始资金的变化；
- 买入持有收益：标的首尾收盘价的变化，用作简单基线；
- 年化收益与年化波动率：便于比较收益速度和路径波动；
- 最大回撤：权益从历史峰值跌到后续低点的最大幅度；
- Sharpe：日收益均值相对日收益波动的比例，按 252 个交易日年化；
- Calmar：年化收益相对最大回撤的比例；
- 已平仓胜率、累计手续费与换手率；
- 交易记录：成交日期、方向、价格、数量与费用。

任何单个指标都不能证明策略有效。至少还要检查样本外表现、换手率、容量、不同市场阶段和参数稳定性。

使用 `-out` 参数可以把结果写成 `summary.json`、`trades.csv` 和 `equity.csv`，后续可以用 Excel、Python 或网页图表分析。

示例数据不足一年，年化收益、Sharpe 和 Calmar 会被短周期放大，只用于验证计算流程，不能当作策略结论。
