# 经典策略：趋势、动量与均值回归

## 双均线趋势

快均线向上穿过慢均线时买入，向下穿过时卖出。

```text
昨天：fast <= slow
今天：fast >  slow  → 次日开盘买入
```

优势是规则清楚、容易验证；缺点是在震荡行情中容易反复交易并产生损耗。

## 截面动量

在同一时点比较多个资产过去一段时间的收益，持有排名靠前者。实现时必须保证：

- 成分列表是当时可知的；
- 排名只使用调仓日前数据；
- 下一交易日才成交；
- 保留没有参与选参的测试区间。

## 时间序列动量

判断单个资产自身过去收益是否为正，并据此决定持有或空仓。它与截面动量的区别是“不与其他资产排名”。

## 均值回归

假设价格或价差偏离均值后会回归，例如：

```text
z = (当前价差 - 滚动均值) / 滚动标准差
```

但相关性不等于协整，历史稳定的关系也可能永久失效。配对交易还会遇到两条腿不能同时成交和卖空受限。

## 策略研究的正确问题

不要只问“哪个参数收益最高”，而要问：

- 参数附近的结果是否也合理？
- 换一段时间、换一个资产是否仍然成立？
- 加入真实成本后是否还有优势？
- 收益是否集中在少数几笔交易？
- 最大回撤是否超过可承受范围？
