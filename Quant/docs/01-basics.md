# 量化基础：数据、收益与交易对象

量化交易不是“让公式预测涨跌”，而是把一个可以复现的想法拆成数据、信号、订单、成交、持仓和风险控制。

```text
历史数据 → 指标/模型 → 交易信号 → 订单 → 成交 → 持仓 → 收益与风险
```

## K 线保存了什么

日线通常包含：

| 字段 | 含义 |
|---|---|
| Date | 交易日期 |
| Open | 开盘价 |
| High | 最高价 |
| Low | 最低价 |
| Close | 收盘价 |
| Volume | 成交量 |

K 线只给出一段时间的统计摘要。仅凭 OHLC 无法知道这一根 K 线内部价格先到最高还是先到最低，因此同一根 K 线内同时触发止盈、止损时，必须明确成交假设。

## 收益率

简单收益率：

```text
r = 当前价格 / 上期价格 - 1
```

多期累计收益不能直接相加，而要复利：

```text
累计收益 = (1+r1) × (1+r2) × ... × (1+rn) - 1
```

## 价格、复权和现实成交

拆股、分红会让原始价格出现跳变。研究信号时常使用复权序列，但订单成交必须对应当时真实可交易的价格。混用两种价格会制造虚假的收益。

## 量化系统中的四个时间

必须区分：

1. 数据什么时候产生；
2. 策略什么时候看见数据；
3. 订单什么时候提交；
4. 订单什么时候成交。

本模块的双均线策略在第 `T` 天收盘后计算信号，最早在第 `T+1` 天开盘成交，避免用尚未结束的收盘数据“穿越”成交。
